API نرخ ارز نِت اَرز همان نرخ‌هایی را که در تابلوی نرخ می‌بینید به‌صورت JSON در اختیار سایت، اپ یا ربات شما می‌گذارد: نرخ لحظه‌ای دلار (تتر) از بازار ایران و ۳۴ ارز دیگر که از برابری جهانی هر ارز با دلار ساخته می‌شوند — با قیمت خرید، فروش، میانگین و تغییر ۲۴ ساعته، همه به تومان.

رایگان با عضویت
یک حساب نِت اَرز بسازید، در پنل «API نرخ ارز» یک اپ ثبت کنید و کلید بگیرید. طرح رایگان کارت بانکی نمی‌خواهد. طرح پرو (۵ دلار در ماه برای هر اپ) نرخ زنده، تاریخچهٔ بلند، هشدار قیمت و استریم را باز می‌کند.

چه چیزی می‌گیرید#
نرخ‌ها
تابلوی کامل یا یک ارز؛ خرید، فروش، میانگین، تغییر ۲۴ ساعته، واحد مظنه.

مبدل
هر جفت ارز، تومان و ریال؛ با نرخ خرید، فروش یا میانگین.

تاریخچه
سری زمانی با بازهٔ دلخواه، JSON یا CSV.

OHLC و آمار
کندل، بیشینه/کمینه/میانگین/نوسان، نرخ در یک لحظه. پرو

هشدار قیمت

استریم زنده
هر تغییر نرخ همان لحظه با SSE. پرو

قفل دامنه
کلید فقط از دامنهٔ تأییدشدهٔ شما کار می‌کند.

اصول پایه#
آدرس پایه: https://netarz.ir/api/fx/v1 — همهٔ مسیرهای این مستندات نسبت به آن هستند.
احراز هویت: هدر Authorization: Bearer fx-ntz-v1-… (یا X-API-Key). کلید در URL پذیرفته نمی‌شود.
قفل دامنه: درخواست مرورگر باید از دامنهٔ ثبت‌شده بیاید؛ درخواست سرور از IP مجاز. جزئیات در قفل دامنه.
واحد: همهٔ قیمت‌ها تومان (IRT) به‌ازای unit واحد از ارز. برای دینار عراق unit برابر ۱۰۰ است.
تازگی: meta.as_of زمان نرخ است؛ در طرح رایگان meta.delayed_minutes می‌گوید چند دقیقه عقب است.
پاسخ‌ها: همیشه JSON با UTF-8، فیلد data برای محتوا و meta برای زمینه؛ خطاها همیشه در error با code ثابت.
زمان‌ها: ISO 8601 با منطقهٔ زمانی. ورودی‌های زمانی Unix timestamp را هم می‌پذیرند.
